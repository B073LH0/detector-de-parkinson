# Diretório de dados

Os dados não são versionados neste repositório.

- Fonte canônica: [UCI Machine Learning Repository — dataset 489](https://archive.ics.uci.edu/dataset/489/parkinson+dataset+with+replicated+acoustic+features)
- DOI: [10.24432/C5701F](https://doi.org/10.24432/C5701F)
- Licença: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- Arquivo esperado para uso local: `data/raw/ReplicatedAcousticFeatures-ParkinsonDatabase.csv`

Crie `data/raw/` somente quando optar pelo download manual. O notebook também pode obter o dataset durante a execução por `ucimlrepo`, com o identificador 489. Ambas as formas são acionadas pelo usuário; nenhum download ocorre na configuração do projeto.

As pastas `raw/` e `processed/` estão ignoradas pelo Git para impedir publicação acidental de dados.
